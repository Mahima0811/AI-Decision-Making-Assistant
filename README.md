# 🤖 AI Decision-Making Assistant

An AI-powered intelligent recommendation platform that helps users compare multiple options, analyze pros & cons, generate smart scores, visualize comparisons, and receive personalized recommendations with useful resources and links.

Built using **Python, Streamlit, OpenAI API, Plotly, and Pandas**.

---

#  Features

##  Smart AI Recommendations

* AI-generated decision analysis
* Personalized suggestions based on user goals and budget
* Structured explanations for better understanding

##  Dynamic Score Analysis

* AI-generated scores out of 10
* Automatic comparison between options
* KPI cards for quick insights

##  Interactive Data Visualization

* Beautiful Plotly charts
* Score comparison graphs
* Modern dark-themed UI

##  Helpful Resources & Links

Based on the user’s category and purpose, the assistant also provides:

* Useful websites
* Official resources
* Tutorials
* Communities/forums
* Buying guides
* Learning platforms
* YouTube channels

##  ChatGPT-like Recent Search History

* Stores previous searches
* Reload previous analyses instantly
* Persistent recommendation history

##  Download Reports

* Export AI-generated recommendations as downloadable reports

##  Modern Responsive UI

* Gradient cards
* Styled tables
* Dark professional theme
* Sidebar navigation

#  Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/Mahima0811/AI-Decision-Making-Assistant.git
```

## 2️⃣ Open Project Folder

```bash
cd AI-Decision-Making-Assistant
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Create Streamlit Secrets File

Create this folder structure:

```text
.streamlit/secrets.toml
```

Add your OpenAI API key:

```toml
OPENAI_API_KEY = "your_api_key_here"

# ▶️ Run Project

streamlit run app.py
